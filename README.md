# bcds-test

This repo is a testbed for work to improve the [B.C. Design System](https://github.com/bcgov/design-system).

If you're here, you were probably sent a link to participate in some user testing. Welcome! Please make a fork of this repo.

Otherwise... there's really nothing interesting going on here.

## What's in this repo

The [`bcds-test-vite`](https://github.com/mkernohanbc/bcds-test/tree/main/bcds-test-vite) folder contains a stock React app scaffolded using Vite. Use this for testing.
